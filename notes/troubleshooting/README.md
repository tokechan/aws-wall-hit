# トラブルシューティング

AWSや関連ツールで困ったこと、調べたこと、原因、解決方法、確認結果を記録します。
原因がまだわからない場合は、確認できた事実と考えられる原因を区別して残します。

[共通テンプレート](../TEMPLATE.md)をコピーして、問題ごとのノートを作成してください。
ファイル名の例：`github-authentication.md`
「具体例・試したこと」には、発生した状況、秘密値を除いたエラー表示、実施した手順と結果を記録します。
