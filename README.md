# aws-wall-hit

AWSを中心とした個人学習の記録を蓄積するリポジトリです。
学んだことを自分の言葉で整理し、理解が深まったら追記・修正し、いつでも振り返れるようにします。
AWSの学習に関連するGit・GitHubなどの周辺ツールについても記録します。

## 目的

- 用語や概念、サービスの仕組みを、自分の言葉で説明できるようにする。
- 実際に試したこと、疑問、問題の原因や解決方法を残す。
- 過去の学びを振り返り、AIとの壁打ちや公式資料との照合に活用する。

## フォルダ構成

```text
aws-wall-hit/
├── README.md                   # 目的・記録方針・学習ノートの目次
├── learning-log.md             # 日付ごとの学習・修正・改善の記録
└── notes/
    ├── TEMPLATE.md             # 学習ノートの共通テンプレート
    ├── concepts/
    │   └── README.md           # 用語・概念の案内と目次
    ├── services/
    │   └── README.md           # AWSサービスごとの案内と目次
    └── troubleshooting/
        └── README.md           # 困ったこと・原因・解決方法の案内と目次
```

## ノートの書き方

1. 関連するノートがあれば読み、新しいテーマなら[共通テンプレート](notes/TEMPLATE.md)をコピーしてノートを作る。
2. 「ひとことでいうと」「理解したこと」「具体例・試したこと」を自分の言葉で記録する。
3. 疑問や未確認の内容は「まだわからないこと」に残し、確認できた内容と区別する。
4. 公式資料を参照したら、URLと確認日を記録する。試した結果には必要に応じて実行日や環境も添える。
5. 追記・修正したノートの更新日を見直し、学習ログに日付・要点・ノートへのリンクを残す。

最初から全項目を埋める必要はありません。テーマや学習段階に合わせて項目を調整します。
ノートにはその時点の理解をまとめ、変更をコミットで残すことで理解の変化も振り返れるようにします。
コマンドやログを記録する際は、トークン、パスワード、秘密鍵などの秘密値を含めません。

## AIとの壁打ちでの使い方

AIがこのリポジトリを参照できる環境で、関連ノートを共有して質問します。
公式情報との照合では、質問時点の公式Docsを確認し、参照URLと確認日を記録します。
自分の理解、公式資料の記述、AIによる説明・推測を区別し、納得できた内容をノートに反映します。

依頼の例：

> 関連する学習ノートを読み、現在の公式Docsと照合してください。
> 僕の理解が合っている部分、修正・補足が必要な部分、まだ確認できない部分を説明してください。
> 参照した公式DocsのURLと確認日を添え、まずノートの修正案を提示してください。

## 運用・改善方針

このリポジトリは、学習の進み方や使いやすさに合わせて、内容と構造を継続的に改善します。

- 理解が深まったり、公式情報が更新されたりしたら、ノートを追記・修正する。
- 分類、フォルダ構成、ノートの書式は、必要に応じて見直す。
- 使いにくい点や改善したい点は、学習ログに記録する。
- ノートを移動・分割した場合は、目次と関連リンクも更新する。
- 大きな変更は、その理由も記録して振り返れるようにする。
